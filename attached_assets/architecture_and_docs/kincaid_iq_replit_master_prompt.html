§ 0 · Non-Negotiable Constraints

The Four Hard Rules

Constitutional. Not subject to engineering trade-off. Code that violates one of these is, by definition, not a Kincaid IQ feature and must be rejected at review.

RULE 01
One screen, four tiles always.
The executive surface is architecturally constrained to four tiles. The constraint prevents the false precision of information overload. Adding a fifth tile must be structurally impossible without changing the layout primitive — enforced at the TypeScript type level as a 4-tuple.
RULE 02
Every number clickable into receipts.
No KPI is rendered without a drill path to the underlying EvidenceRef. The drill is a first-class UI affordance, not a tooltip. Implemented as a routed deep-link, not a modal.
RULE 03
No export without receipts.
Any PDF, CSV, or JSON export carries a cryptographic manifest — SHA-256 of every cited EvidenceRef, TransformRef, PolicyResult. Exports without the manifest are rejected at the RENDER gate.
RULE 04
Narratives never outrun evidence.
Generative language is gated behind deterministic computation. The narrative cites; it does not infer. If the math returns INSUFFICIENT_EVIDENCE, the narrative says so — it does not paper over the gap.

§ 2 · The Four Core Primitives

Constitutional first-class objects.

Pydantic v2, frozen. A field is not "typed after import"; it is typed as a precondition of being a field. Mutation attempts must raise. The primitives are the substrate — every gate, every engine, every endpoint operates on these and only these.

PrimitivePurposeCritical fields
EvidenceRef Content-addressed evidence pointer evidence_id · source_hash (SHA-256) · vintage_year · parent_evidence_id
TransformRef Versioned computation pointer code_hash · input_evidence_ids · output_hash · superseded_by
PolicyResult Gate verdict verdict (PASS/FAIL/WAIVED) · gate · rationale · citation
Claim Atomic financial record paid_amount · allowed_amount · ndc/cpt · evidence_id · member_id_hash
Design Property

A TransformRef is never mutated. Refinements create a new TransformRef with superseded_by set on the prior version. This is the constitutional alternative to Power Query's "Insert Step After" — full lineage, no in-place mutation, every refinement auditable.

§ 4 · Confidence Tiering

Three labels. No fourth.

Every finding is labeled with exactly one tier. The tier governs whether the finding can render to a board-facing surface. The absence of a number is itself an evidence-integrity signal — not a gap to be hidden.

5.3 · DRAP — Delta Realized vs. Allowable Pricing

# For each claim c:
allowable_c   = benchmark.lookup(c.ndc or c.cpt, c.service_date, c.pos)
delta_c       = c.paid_amount − allowable_c

DRAP_total    = Σ delta_c
DRAP_per_PEPM = DRAP_total / member_months
EBITDA_impact = DRAP_total   # the dollar is the EBITDA dollar

Benchmark sources: NADAC (rx), CMS Fee Schedule (medical), DOL 5500 Schedule C peer set (admin). The benchmark itself is an EvidenceRef with its own vintage_year.

§ 6 · The Evidence Spine

Append-only. SHA-256 sealed. Inviolable.

Postgres-backed. Every entry carries a chain_hash = SHA-256(prior_chain_hash || source_hash). Retroactive tampering invalidates every downstream entry. Nightly verify_spine_integrity() job emits a PolicyResult at gate PROMOTE.

CREATE TABLE evidence_spine (
    evidence_id        TEXT PRIMARY KEY,
    source_hash        CHAR(64) NOT NULL UNIQUE,
    source_type        TEXT NOT NULL,
    source_uri         TEXT NOT NULL,
    captured_at        TIMESTAMPTZ NOT NULL,
    vintage_year       INT NOT NULL,
    parent_evidence_id TEXT REFERENCES evidence_spine(evidence_id),
    chain_hash         CHAR(64) NOT NULL,    -- SHA-256(prior || source)
    sealed_at          TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

REVOKE UPDATE, DELETE ON evidence_spine FROM PUBLIC;

§ 9 · Build Order

Sequential. Acceptance-gated.

Execute in order. Do not advance until the prior step's acceptance test passes. Steps 1–3 are non-negotiable foundations. Steps 4–6 deliver the deterministic substrate. Steps 7–10 surface it.

  1. Repo scaffold · .replit · replit.nix · both processes start
    curl -H "Authorization: Bearer $TOKEN" localhost:8000/api/v1/health → 200; unauthenticated → 401
  2. Four primitives as Pydantic frozen dataclasses + unit tests
    pytest backend/tests/test_primitives.py green; mutation attempts raise ValidationError
  3. Evidence Spine schema + Alembic migrations + verify_spine_integrity()
    Empty-spine integrity check returns PASS; tampered chain_hash returns FAIL with diagnostic
  4. Gates 1–3 — DEFINE, WIRE, VALIDATE
    Ingest sample PBM claims CSV; all three gates emit PolicyResults; malformed data fails VALIDATE with typed error
  5. Gates 4–7 — PROMOTE, COMPUTE, GATE, RENDER for DRAP
    Compute DRAP on synthetic data; result includes confidence tier, transform_id, evidence_ids[]
  6. PEPM · PBM Waste · SBI · GLP-1 · EBITDA Scenario engines
    Each engine asserts determinism: identical input → identical output_hash across N=100 runs
  7. API routes for compute and receipts
    httpie hits every endpoint with bearer; receipts resolve full lineage chain to spine entries
  8. Frontend scaffold · design tokens · FourTileSurface component
    Four tiles render at /; TypeScript prevents adding a fifth tile at compile time
  9. Receipt drill UX · ConfidenceChip · FiduciaryPostureGauge
    Every number on surface deep-links to /receipt/:kpi_id; chip colors match tier verdict
  10. Board packet export with cryptographic manifest
    Exported PDF opens; manifest.json attached; every cited hash resolves to a spine entry
§ 10 · Category Discipline

What this build is not.

State these in the agent's working memory. They prevent category drift — the most common failure mode when an LLM-driven build is left unsupervised.

NOT A DASHBOARD
Dashboards show numbers. This shows receipts. A surfaced number without a drill path is a constitutional failure.
NOT A CONSULTING ACCELERATOR
If a feature is implementable in Power Query / Alteryx / Power BI within one engagement cycle, it is not a Kincaid IQ feature. Reject the build.
NOT A BROKER TOOL
Buyer is the CFO, the PE operating partner, the M&A deal team, the board, the family office. UX calibrated to that audience.
NOT A HEALTHCARE ANALYTICS PLATFORM
Fiduciary-grade financial infrastructure that happens to deploy in healthcare first. Comp set: Palantir, Snowflake, Databricks.
NOT A GENERATIVE-AI PRODUCT
Generative outputs are gated, cited, admin-approved. Deterministic math is the substrate; narrative is the surface; the layers never merge.
NOT FOR HR
HR is not the buyer. The product is fiduciary-grade infrastructure for the people who carry fiduciary obligation.
